# 📊 IPL Data Analytics Charts

This folder contains data visualizations created as part of the IPL Data Analytics project (2008–2025).

## Charts Included

- Top 10 IPL Teams by Total Wins
- IPL Matches Played in Each Season
- Season-wise Wins by Top 5 IPL Teams
- Season-wise Toss Decisions
- Matches Played vs Matches Won
- Team-wise and Season-wise Performance

## Tools Used

- Python
- Pandas
- Matplotlib
- Google Colab

These visualizations help explore team performance, seasonal trends, and match outcomes in the Indian Premier League.

For the complete project, visit the [IPL Data Analytics Repository](https://github.com/ankitkumar8770/IPL-Data-Analytics).
